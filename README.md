# 🎂 Квест ко дню рождения — 71

Приключенческий квест из **6 мини-игр** и поздравления в финале.
Сделано для папы на 71 год: запускается на iPhone и на Windows, работает без интернета.

Никаких установок, сборки, серверов и интернет-зависимостей — просто HTML, CSS и JavaScript.

---

## Что внутри

| Испытание | Что делать |
|---|---|
| 🔤 **Пять букв** | Угадай слово из 5 букв (Wordle). Словарь — 203 ответа с подсказками + 122 дополнительных слова. Клавиша **⌫** (или кнопка «⌫ Удалить букву») стирает последнюю букву. |
| 🀄 **Маджонг** | Собери 40 пар плиток. Среди символов — 🕊️ 🌺 🎂 🧉. Гарантированно проходимая раскладка, есть подсказка, «перемешать» и «решить». |
| ♠ **Пасьянс** | Клондайк: 52 карты, 4 стопки. Тащи мышкой или пальцем, можно просто нажимать. Есть «отменить» и «автодобор», счётчик карт в колоде. |
| 🎴 **Найди пару** | Открывай карточки и находи одинаковые: 6–12 пар, сетка сама подстраивается под экран. |
| 🧩 **Слова по кругу** | Веди палец (или мышь) по буквам вокруг круга и собирай слова. Найденные слова сами встают в клетки кроссворда. |
| ❓ **Викторина** | 9 вопросов про именинника с пояснениями. |

За каждое пройденное испытание ты находишь **фрагмент письма**. В конце — подарок и поздравление.

---

## 💾 Прогресс сохраняется сам

- Прогресс, найденные фрагменты, имя и результаты пишутся в `localStorage` **сразу после каждого события** —
  можно закрыть вкладку, перезагрузить страницу или выключить телефон и вернуться позже.
- Подтверждение сохранения показывается зелёной плашкой «✓ Прогресс сохранён».
- Дополнительно страховка: сохранение срабатывает при уходе со страницы и при сворачивании окна.
- Сбросить всё: «Настройки» → «Сбросить весь прогресс».

## 🔑 Секрет (для того, кто дарит)

На **компьютере** нажми клавишу **Ё** — и все шесть испытаний откроются разом, можно играть в любом порядке.
Подсказка: в окне «Как играть» есть намёк на секретный ключ.

На телефоне секрет не работает: там нет клавиши «Ё» (и нечего нажимать).

## Как открыть

### 📱 На iPhone (iOS)

1. **AirDrop** папку с quest на iPhone (или скиньте файлы в «Файлы» / iCloud).
2. В «Файлах» открой папку и тапни **index.html** — он откроется в Safari.
   * Если Safari откроет как «файл», а не страницу: отправьте себе ссылку на файл и откройте её.
   * Либо положите папку на любой хостинг (GitHub Pages, Яндекс.Диск → публичные страницы) и откройте ссылку.
3. В Safari нажмите **«Поделиться» → «На экран „Домой“»** — квест появится как отдельное приложение с иконкой, будет работать офлайн.

> Чтобы работало офлайн, лучше открывать **по http** (тогда включается service worker и кеширование).
> При открытии из «Файлов» интернет не нужен: все файлы уже локальные.

### 💻 На Windows

1. Откройте папку и дважды кликните **index.html** — откроется браузер, всё работает.
2. Если хотите офлайн-режим с иконкой — откройте папку в терминале и запустите:

```powershell
powershell -ExecutionPolicy Bypass -File tools\serve.ps1 -Port 8733
```

   затем откройте <http://localhost:8733/>.

> Скрипт `tools/serve.ps1` — простой локальный сервер **только для удобства**. Он не обязателен.

## Как настроить под себя

Всё настраивается в одном файле: **`js/config.js`**. Код трогать не нужно.

```js
birthday: {
  name: 'Папа',        // как обращаться
  age: 71,             // сколько лет
  date: '21 октября',  // дата праздника
  title: 'С Днём Рождения!',
  intro: '...',        // подпись на титульном экране
  finalText: '...'     // текст поздравления в финале
}
```

Что ещё можно менять в том же файле:

| Ключ | Что это |
|---|---|
| `answers` | Ответы для «Пяти букв»: `{ w: 'слово', h: 'подсказка' }`. **Ровно 5 букв!** Слова другой длины игра сама отфильтрует. |
| `extraWords` | Дополнительные слова — их можно только вводить, они не будут ответом. Тоже по 5 букв. |
| `quiz` | Вопросы викторины: `{ q: 'вопрос', a: ['вариант1','вариант2','вариант3','вариант4'], c: 0, note: 'пояснение' }` (`c` — номер правильного ответа, с нуля). |
| `fragments` | Фрагменты письма — по одному на каждое испытание. |
| `memoryIcons` | Значки для игры «Найди пару». |
| `wordWheel` | Игра «Слова по кругу»: `letters` — буквы на колесе, `words` — слова из этих букв. Каждое слово должно состоять только из этих букв. |

После правок просто обновите страницу — прогресс сохранится.

## Структура проекта

```
index.html            — каркас страницы
css/styles.css        — всё оформление и анимации
js/config.js          — ← НАСТРОЙКИ (тексты, слова, вопросы)
js/app.js             — карта квеста, экраны, модалки, сохранение прогресса
js/sfx.js             — звуки (WebAudio, без файлов)
js/confetti.js        — конфетти на canvas
js/games/*.js         — шесть мини-игр
manifest.json + sw.js — офлайн-режим (работает только по http/https)
icons/                — иконки приложения
tools/serve.ps1       — локальный сервер для разработки
tools/test.js         — автотест (см. ниже)
tools/make-icons.ps1  — генерация иконок
```

Прогресс сохраняется в `localStorage` (ключ `quest71.v1`), поэтому перезагрузка страницы ничего не теряет.

## Автотест

Откройте квест по `http://localhost:8733/`, откройте консоль браузера и выполните:

```js
fetch('/tools/test.js').then(t => { (0,eval)(t); window.__questTest(); })
```

Результат — в `window.__testResults`, список ошибок — в `window.__testErrors`.
Тест управляет случайностью и сам проходит все шесть игр, поэтому результат всегда одинаковый.
Сейчас в нём **86 проверок**: интерфейс всех игр, словарь, Backspace, замочки на карте,
секретная клавиша «Ё», распределение символов в маджонге, размеры карт, кроссворд «Слова по кругу»,
подгонка сетки пар под экран и сохранение прогресса.

## Поддержка

- Работает в Safari (iOS/macOS), Chrome, Edge, Firefox.
- Проверено на ширинах экрана 320 / 390 / 430 px — горизонтальной прокрутки нет нигде.
- Интернет нужен только для первого открытия по http (дальше работает офлайн).
- Звук включается кнопкой «♪» в настройках.
- Чтобы начать заново: «Настройки» → «Сбросить прогресс».
